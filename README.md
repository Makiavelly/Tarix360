# Tarix 360

Интерактивная игра об истории Татарстана: игрок осматривает 360°-панораму, отмечает место и год, а затем получает точность ответа и историческую справку.

## Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd WenWareTatarV2
```

## Запуск без Docker

Понадобятся:

- Go 1.23 или новее;
- Node.js 22 или новее;
- npm, устанавливается вместе с Node.js.

Бэкенд и фронтенд запускаются в двух отдельных терминалах.

В первом терминале запустите Go-бэкенд:

```bash
cd backend
go run ./cmd/server
```

API будет доступен по адресу <http://localhost:8080>.

Во втором терминале установите зависимости и запустите фронтенд:

```bash
cd frontend
npm install
npm run dev
```

После запуска откройте <http://localhost:5173>. Vite автоматически проксирует запросы API и панорам в Go-сервис. Команду `npm install` достаточно выполнять после первого клонирования и при изменении зависимостей.

На Windows эти же команды можно выполнять в PowerShell. Наличие `make` не требуется. Если `make` установлен, из корневой папки доступны сокращённые команды:

```bash
make backend   # первый терминал
make frontend  # второй терминал
```

## Запуск через Docker

Понадобятся Docker и поддержка Docker Compose. Из корневой папки проекта выполните:

```bash
docker compose up --build
```

После сборки приложение будет доступно по адресу <http://localhost:3000>, а API — по адресу <http://localhost:8080>.

Для запуска в фоновом режиме:

```bash
docker compose up --build -d
```

Просмотр журналов контейнеров:

```bash
docker compose logs -f
```

Остановка приложения:

```bash
docker compose down
```

При последующих запусках, если исходный код не менялся, повторная сборка не обязательна:

```bash
docker compose up
```

Для загрузки современной карты в обоих вариантах запуска требуется интернет-доступ к `tile.openstreetmap.org`. Ключ API не нужен. Если карта не отображается, проверьте VPN или сетевую блокировку этого домена.

## Архитектура

```text
backend/
  cmd/server/                  composition root
  internal/domain/            сущности и контракты репозиториев
  internal/repository/        файловый каталог и in-memory игровые сессии
  internal/service/           сценарии игры и подсчёт результата
  internal/transport/httpapi/ HTTP-транспорт
  storage/events.json         метаданные уровней
  storage/panoramas/          локальные equirectangular-панорамы
frontend/
  src/domain/                 клиентские модели
  src/repositories/           HTTP-адаптер
  src/services/               сценарии и сохранение игровой сессии
  src/components/             панорама, карта, выбор времени
  src/screens/                главная, игровой раунд, итоги
```

Правильные ответы остаются на сервере до отправки догадки. Игровая сессия хранится в памяти процесса, а её идентификатор — в `localStorage`, поэтому страницу можно обновить и продолжить текущую игру. Для современной карты используется OpenStreetMap через Leaflet: ключ API не нужен, но для загрузки картографических тайлов требуется интернет. Панорамы и игровая логика работают локально.

## Добавление уровня

1. Положите equirectangular-изображение с пропорцией 2:1 в `backend/storage/panoramas/`.
2. Добавьте событие в `backend/storage/events.json`: год, координаты, описание, имя файла и `type`. Тип `history` включает общую историческую музыку, `legend` — сказочную, `culture` — культурную.
3. Добавьте событию ровно три объекта `hotspots`. Для каждой точки нужны уникальный `id`, заголовок, описание, тип (`time`, `place` или `context`) и положение на сфере: `yaw` от −π до π и `pitch` от −π/2 до π/2. Точки передаются клиенту только после ответа игрока.
4. Если для того же места есть виды других лет, добавьте их в `alternatePanoramas`. Для каждого вида укажите `year`, `title`, `description` и имя файла `panorama`. После ответа игрок сможет переключаться между всеми годами.
5. Перезапустите бэкенд. Новый уровень автоматически войдёт в случайный маршрут.
